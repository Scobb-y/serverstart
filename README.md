REQUIRED TO USE:
- You must have Java installed and added to the path in your .env file to run Minecraft servers. The version depends on the Minecraft version
- Install Node.js version 18 or newer
- You must create a ".env" file. Copy and paste the contents inside "sampleenv" and replace information as needed.
- To make your server viewable on your network only, replace "(YOUR IP GOES HERE)" with your private IPv4 address. To make it viewable from any device over the internet, use your public IPv4 address.
- Run "npm install" in the terminal
- Run "npm run build" in the terminal

TO RUN THE SERVER:
- The JAR file used to run the server must be alphabetically highest in the directory if multiple JAR files are present
- Navigate to the main directory and type "npm run backend" in the terminal
