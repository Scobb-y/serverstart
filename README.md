REQUIRED TO USE:
- You must create a ".env" file. Inside the main file, paste this VITE_API_URL=http://(YOUR IP GOES HERE):3000
- To make your server viewable on your network, replace "(YOUR IP GOES HERE)" with your private IPv4 address. To make it viewable from any device over the internet, use your public IPv4 address.
- Inside the main file paste ROOT_FOLDER="(Your servers directory goes here)"
- Paste your server directory path into the quotations

TO RUN THE SERVER:
- Navigate to the main directory and type "npm run backend" in the terminal
